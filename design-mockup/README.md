# Design mockup

`workflow-hub.html` is a clickable, single-file sketch of the redesigned Workflows area: sidebar layout, Workflows, Reviews, Assign, Process map and Training. It uses sample data only and needs no server: open the file in a browser.

The **Viewing as (sketch only)** dropdown in the sidebar switches between a Manager, an Admin and several Employees, so you can see what each role gets. That dropdown, and the "Sketch only · preview as" dropdown on Training, exist only in this mockup. They do not ship in the product.

The mockup is the reference for the real pages in `src/app`. Where the two differ, the mockup shows the intended design.
